# No backward compatibility

`@shotgunlive/mesh` is unreleased and every device in a mesh runs the same build. Change the wire format, the native module API and the public JS API freely: no protocol version bumps, "v2" formats, migrations, fallbacks, decode paths for old packets or deprecation shims. Update every call site, the example app and the docs in the same change instead.
